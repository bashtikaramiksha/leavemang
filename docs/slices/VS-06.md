# VS-06 — Leave History & Dashboard

## Summary
VS-06 gives employees and managers a clear view of leave information after the request and approval workflow is complete. An employee can view their leave balance and complete leave history, while a manager can view team-level leave information and filter leave requests by status and employee.

This slice is primarily a read/reporting slice. It consumes finalized data from VS-03, VS-04, and VS-05 without duplicating their business logic or modifying data.

---

## 1. Slice Context
```
VS-03 (Leave Types + Balance)
       │
       ▼

       │
       ▼

       │
       ▼
┌─────────────────────────┐
│          VS-06          │
│   History & Dashboard   │
└───────────┬─────────────┘
            │
   ┌────────┴────────┐
   ▼                 ▼
Employee View   Manager View
```

---

## 2. Success Criteria
- Employee can view current leave balances (Allocated, Used, Remaining).
- Employee can view all their leave requests & request status.
- Employee can see rejection reasons for rejected requests.
- Employee can view request details.
- Manager can view team leave requests.
- Manager can filter requests by status (All, Pending, Approved, Rejected).
- Manager can filter requests by employee.
- Manager can see basic leave statistics (Total Requests, Pending, Approved, Rejected, Approved Days).
- Users cannot see data outside their authorization scope (Employee data isolation, Manager-only dashboard).
- Tests pass.

---

## 3. Atomic Requirements
- **AR-01 Employee Dashboard**: Employee can view their leave summary.
- **AR-02 Balance Summary**: Employee sees Allocated, Used, Remaining for each leave type.
- **AR-03 Leave History**: Employee sees their previous leave requests.
- **AR-04 Request Status**: Each request displays its current status.
- **AR-05 Rejection Reason**: Rejected requests display the rejection reason.
- **AR-06 Request Details**: Employee can open a request and see its details (including reviewer info and timestamps).
- **AR-07 Manager Dashboard**: Manager can view leave information for employees within permitted scope.
- **AR-08 Status Filter**: Manager can filter by All, Pending, Approved, Rejected.
- **AR-09 Employee Filter**: Manager can filter requests by employee.
- **AR-10 Summary Statistics**: Manager sees basic leave statistics (Total, Pending, Approved, Rejected, Approved Days).

---

## 4. Business Rules
- **BR-01 Employee Data Scope**: Employee can only view their own leave balance, requests, and details. Employee A cannot access Employee B's history.
- **BR-02 Manager Data Scope**: Manager can view requests belonging to employees within management scope (Manager → All employees in current scope).
- **BR-03 Approved Requests**: Approved requests appear as Approved and contribute to approved leave statistics.
- **BR-04 Rejected Requests**: Rejected requests remain in history with rejection reasons and are not deleted.
- **BR-05 Pending Requests**: Pending requests remain visible until VS-05 changes their status.
- **BR-06 Balance Is Read-Only**: Dashboard must not modify Allocated, Used, or Remaining balance.
- **BR-07 Statistics Are Derived**: Calculate statistics dynamically from leave request data rather than storing counters.

---

## 5. Routes
### Employee Routes
- `GET /my/dashboard`: Employee dashboard (balances summary + recent leave requests)
- `GET /my/leave-requests`: Full employee leave history
- `GET /my/leave-requests/{id}`: Request details
- `GET /my/leave-balances`: Employee leave balances

### Manager Routes
- `GET /manager/dashboard`: Manager dashboard (statistics cards + team requests table)
- `GET /manager/leave-requests`: Filtered team requests (`?status=...&employee_id=...`)
- `GET /manager/leave-requests/{id}`: Manager request details

---

## 6. Acceptance Tests (AT-01 to AT-10)
- **AT-01**: Employee Dashboard shows balances and recent requests.
- **AT-02**: Employee History shows all requests for employee.
- **AT-03**: Employee Isolation ensures Employee A cannot see Employee B's data.
- **AT-04**: Rejection Reason displayed on request details for rejected requests.
- **AT-05**: Manager Pending Filter displays only Pending requests.
- **AT-06**: Manager Employee Filter displays only selected employee's requests.
- **AT-07**: Dashboard Statistics show correct counts (Total, Approved, Pending, Rejected).
- **AT-08**: Approved Days calculated as sum of days of approved requests.
- **AT-09**: Employee cannot access Manager dashboard (403 Forbidden).
- **AT-10**: Balance is read-only when viewed on dashboard.
